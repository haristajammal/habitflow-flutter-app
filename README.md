# ✨ HabitFlow – Flutter Habit Tracker

**HabitFlow** is a simple and elegant habit-tracking mobile application built with Flutter. It helps users build positive habits, stay consistent, and track their daily progress.

The application features a premium **Black & Gold** design for a clean and modern user experience.

## 📱 Features

- **Add Habits:** Create new habits according to your personal goals.
- **Edit Habits:** Update existing habit details.
- **Delete Habits:** Remove habits whenever needed.
- **Custom Icons:** Choose icons for your habits.
- **Daily Tracking:** Mark habits as completed.
- **Progress Tracking:** Monitor your daily habit completion.
- **Dark Theme:** Enjoy a premium black and gold interface.
- **Theme Preference:** Switch between dark and light themes.
- **Local Storage:** Save habits and preferences using SharedPreferences.
- **Daily Motivation:** Get motivational quotes to stay consistent.

## 🛠️ Technologies Used

## 📦 Build APK

To generate a release APK, run:

```bash
flutter build apk --release --no-tree-shake-icons
```

The APK will be generated at:

```text
build/app/outputs/flutter-apk/app-release.apk
```
